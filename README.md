# Forecasting the Inflation Trend in Pakistan Using a VAR Model

BS research project by Muhammad Arsim.

## Summary
This study forecasts Pakistan's CPI using a Vector Autoregressive (VAR) model
with oil (petrol) prices and the PKR/USD exchange rate.
Data: monthly, September 2018 to September 2023 (61 observations).
Software: EViews.

## Files
- Arsim_Inflation_VAR_Research.pdf : presentation (view in browser)
- Arsim_Inflation_VAR_Research.pptx : editable slides

## Methods
Unit root (ADF), Granger causality, VAR lag selection, VAR estimation,
residual LM test, forecast evaluation.
